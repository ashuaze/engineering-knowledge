# 微调与蒸馏：模型学会示例，为什么仍需独立评估

学习入口：模型更像训练样例，或学生模型能模仿教师，为什么仍可能在新输入、拒绝和业务约束上失败？训练目标、数据范围和应用正确性需要分别验证。

前置：[评价与失败分析](evals-and-failure-analysis.md)、[上下文与记忆](tokens-context-and-memory.md)。本文参考Transformers/PEFT与Hinton等人的原论文相关段落，例子为纸面设计；未取得训练数据、创建训练任务、加载模型或生成教师输出。

## 提示、检索和参数训练改变不同部分

| 方法 | 主要改变什么 | 不能自动获得什么 |
| --- | --- | --- |
| 提示/示例 | 本次或会话中的输入上下文 | 参数永久学习和持续权限控制 |
| 检索 | 为本次请求提供外部资料 | 资料真实、完整或推理必然正确 |
| [微调](../../glossary/ai.md#ai.training) | 用训练目标更新模型参数或适配参数 | 最新事实、全部边界及外部执行安全 |
| 蒸馏 | 用教师信号训练学生模型 | 教师所有能力及更低的实际成本 |

[Transformers Fine-tuning](https://huggingface.co/docs/transformers/main/en/training)以预训练模型继续训练说明参数适配。训练可改善某类任务或风格，但不应把频繁变化的库存或当前对象权限仅依赖模型记忆；这些仍需可信数据和执行检查。

## 全量更新与参数高效方法有不同成本

全量微调可以更新大量基础参数；参数高效方法只训练部分参数或新增适配结构。[PEFT LoRA说明](https://huggingface.co/docs/peft/main/en/conceptual_guides/lora)描述低秩更新矩阵及其规模因素。

训练参数较少可能降低某些存储与训练成本，却不保证推理更快或质量不变。基础模型、适配器、合并方式和运行配置需要共同版本化；仅保留一个适配器文件不一定足以重现整个部署。

## 蒸馏的信号可以是分布，也可以是生成样例

[Hinton、Vinyals与Dean原论文](https://arxiv.org/pdf/1503.02531)讨论用教师的软目标分布训练学生：除了最高类别，其他类别的相对概率也可以传递信息。本文只引用软目标与[温度](../../glossary/ai.md#ai.sampling)相关机制，不复现其分类/语音实验。

对于生成应用，也可用教师产出的文本或其他可获得信号构造训练样例；[Kim与Rush的序列级蒸馏研究](https://arxiv.org/abs/1606.07947)提供了相关方法例子。只拿到最终文本，不等于拿到了完整概率分布，两种训练证据不能混为一谈。学生可能继承教师错误，也可能受自身容量、目标和数据分布限制。

蒸馏中的温度可以服务于训练软目标，推理时的温度则控制解码；用途和所处阶段不同，不能认为降低推理温度就完成了蒸馏。

## 数据划分要防止目标答案泄漏

先说明任务范围、数据来源与使用条件，检查重复、标签质量、敏感内容和版本。训练集用于更新参数，验证集支持选择方案，最终测试集尽量保留为独立评估；按用户、来源或时间等划分时，还需防止近重复跨集合泄漏。

教师生成训练样例后，又让同一教师按相似措辞评价学生，可能偏向模仿而非实际目标。可以结合独立人工/程序判定、真实任务结果与不同失败切片；每种判定本身仍有范围和误差。

## 纸面得分不能独自说明泛化或收益

假设同一套100道未用于训练或方案选择的测试题中，基线答对88道、适配后答对92道，观测正确率为88%与92%，增加4个百分点。这是给定计数，不是本篇实验，也不能仅凭一轮小样本宣称普遍提升。

还要检查具体哪些题由对变错、长尾输入、拒绝、资料不足和外部效果；同时比较[延迟](../../glossary/performance.md#performance.latency-throughput)、资源和全流程成本。教师生成、数据治理、训练和评估本身也有成本，不应只比较学生单次推理。

数据删除或[授权](../../glossary/security.md#security.identity)撤销也不能仅靠从训练目录移除原文件就认定模型影响已消失；训练、模型/适配器版本和运行数据需要各自治理，见[记忆权限与删除](memory-access-revocation-and-deletion.md)的边界区分。

## 自检

1. 提示、检索、微调与蒸馏分别改变什么？
2. LoRA训练参数少，为什么不自动证明推理更快或部署可复现？
3. 软目标分布与教师最终文本有什么区别？训练温度和解码温度又有何不同？
4. 为什么训练、方案选择和最终测试需要划分，并检查近重复？
5. 88/100到92/100增加多少？为何仍需检查失败切片与全流程成本？
