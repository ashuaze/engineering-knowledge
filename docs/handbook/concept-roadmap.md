# 概念路线图

这份路线图按知识领域展示已有阅读入口和待深入的机制。可根据当前任务、已有基础与文章的前置知识选择阅读顺序，不必从头读完。

目前共有 201 篇正文，17 个领域均有概念正文。请求处理、数据访问、资源与故障边界已有阅读入口；AI 方向也增加了上下文、检索与评价的基础说明。现有313组术语均已关联正文，但有入口不表示组内所有子概念和该领域全部知识已深入解释，具体范围与证据以正文说明为准。

系统与网络、安全与 API、分布式与数据的逐项阅读证据见[三条主线覆盖清单](concept-coverage.md)。它将专题、关联与待补范围分开，概念解释和真实实验分别验收；不以术语组挂接文章计算完成率。
